# Website redesign audit checklist

A fillable, Tiller-branded version of the Website Redesign Audit Checklist from the guide
[20 questions to ask before a website redesign](https://tillerdigital.com/guides/website-audit-checklist-20-questions-to-ask-before-a-website-redesign/).
Rate each question green, yellow or red and add notes. Answers stay in your browser.
