# Website redesign audit checklist

A fillable, Tiller-branded version of the Website Redesign Audit Checklist that goes with the guide
[20 questions to ask before a website redesign](https://tillerdigital.com/guides/website-audit-checklist-20-questions-to-ask-before-a-website-redesign/).

Rate each question (Strong / Needs work / Major gap / Not sure), add notes, and get a score per section plus a
starting recommendation: CRO optimization, partial refresh or full redesign. Answers save in the browser, and
the results print to PDF or download as CSV. The original Google Sheet stays available as a copy/download.

Prototype for review. The email form is a preview and sends nothing.
